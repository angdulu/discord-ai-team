# How to work in this folder

This folder is the shared memory for a small AI team (Claude, Codex, Gemini) planning a side project.
Every agent reads these same rules.

- Start from `index.md`. It lists every note with a one-line summary.
- One topic per note, in `notes/`. Link notes with [[note-name]].
- When you change or add a note, update `index.md` and add one line to `log.md` (date, who, what).
- Keep facts and opinions apart: mark guesses as **Assumption:**.
- The project owner makes final decisions. Propose, argue, and summarize, but do not mark anything "decided" unless the owner said so.
- Be concise. Bullet points over paragraphs.
